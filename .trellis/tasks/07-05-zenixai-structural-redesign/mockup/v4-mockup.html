600px 宽屏，代码块可以完整展示 50+ 字符不折行:

pub(super) fn render_message(msg: &ChatMessage, theme: &Theme) -> AnyElement {
    let is_user = msg.role == "user";
    let content = markdown::render_markdown(&msg.content, theme);
    if is_user {
        // accent background bubble, right-aligned
        v_flex().items_end().child(div().max_w(px(480.)).bg(theme.accent)...)
    } else {
        // muted background bubble with avatar
        v_flex().child(h_flex().child(avatar).child(div().bg(theme.muted)...))
    }
}
600px · comfortable · 宽屏代码不折行
  • 拖拽分隔条: chat 面板左边缘 5px 宽，hover/dragging 时变 accent 蓝高亮
  • clamp 范围: 360px (min) ~ 720px (max)；min 保证可读性，max 防止终端被挤压 < 400px
  • 响应式内容: 消息气泡 max_w 用百分比 (88%)，不是硬编码 px
  • 代码块自适应: 窄屏代码块出现水平滚动；宽屏代码不折行
  • 持久化: 拖拽结束 (on_drop) 时存到 ~/.config/zenix/config.json 的 ai_panel_width 字段
  • 窗口缩小告警: 当终端宽度 < 400px 时，面板顶部显示细黄条提示
vs 现状: 现 AI_PANEL_WIDTH = 420.0 硬编码常量 (chat/mod.rs:41)，不可调；代码块在窄屏经常折行难读
