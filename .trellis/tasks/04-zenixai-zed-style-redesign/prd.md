# PRD: zenixAI Zed 风格界面重构

## 背景与问题
当前的 zenixAI 会话界面虽然进行了初步的样式调整，但没有真正理解 Zed Agent 的 UI 设计模式，导致界面效果没有实质性改善。

## 目标
基于 Zed Agent 的 UI 设计模式，完全适配 zenix 的架构，重构 zenixAI 的会话界面，实现：

1. **极简顶部导航栏**：
   - 左侧显示"ZenixAI"字样并附带下拉箭头（▾）
   - 右侧放置搜索（🔍）和更多选项（⋯）图标

2. **清晰的输入区与占位符**：
   - 占位符文本："Message the ZenixAI Agent, @ to include context, / for commands"
   - 使用低对比度灰色（#6e6e6e 或 hsla(0.0, 0.0, 0.44, 1.0)）
   - 输入框背景色为极淡的灰色，边框为更淡的灰色

3. **底部模型选择面板**：
   - 显示"Select a model…"附带下拉箭头
   - 下方有"Configure"按钮
   - 右侧附带快捷键提示"Ctrl-Alt-C"

4. **底部操作栏极简化**：
   - 左侧："+"号图标（用于添加新会话或上下文）
   - 中间：AI Agent/设置图标（⚙），以及文本"ZenixAI Agent"或"Agents (n)"附带下拉箭头（▾）
   - 右侧：极简的"发送/播放"按钮（▶图标）或停止按钮（◼）

## 技术实现要点
- 使用 gpui-component 库的现代化样式
- 保持与现有主题系统的兼容性
- 适配 zenix 的 AI 引擎和会话管理架构

## 验收标准
- [ ] 顶部导航栏符合 Zed 风格
- [ ] 输入区占位符文本和样式正确
- [ ] 底部模型选择面板结构正确
- [ ] 底部操作栏极简化布局正确
- [ ] 整体界面符合现代 AI Agent 风格
