# Design: zenixAI 会话界面重新设计

## 设计原则
1. **Modern Minimalist**: 采用现代极简设计风格，参考 Linear、Vercel、Cursor 等现代 AI 工具
2. **Clear Hierarchy**: 清晰的视觉层级，通过颜色、大小、间距区分重要程度
3. **Consistent Styling**: 统一的圆角、阴影、颜色系统
4. **Responsive Layout**: 适应不同屏幕尺寸，保持良好的可读性

## 颜色系统
基于现有主题系统，定义以下颜色变量：

### 消息气泡颜色
- **用户消息背景**: `gpui::rgba(0x3B82F620)` 或主题色渐变 (blue/indigo/purple)
- **用户消息边框**: `gpui::rgba(0x3B82F640)`
- **AI 消息背景**: `gpui::rgba(0xFFFFFF08)`
- **AI 消息边框**: `gpui::rgba(0xFFFFFF10)`

### 状态颜色
- **运行中**: `gpui::hsla(0.55, 0.8, 0.6, 1.0)` (蓝色脉冲)
- **已完成**: `gpui::hsla(0.33, 0.7, 0.5, 1.0)` (绿色)
- **失败**: `gpui::hsla(0.0, 0.8, 0.55, 1.0)` (红色)
- **代理状态 - working**: `gpui::hsla(0.33, 0.7, 0.5, 1.0)`
- **代理状态 - blocked**: `gpui::hsla(0.08, 0.9, 0.55, 1.0)`
- **代理状态 - done**: `gpui::hsla(0.0, 0.0, 0.5, 1.0)`

## 组件设计详情

### 1. Header 组件
```
┌─────────────────────────────────────────────────────────┐
│  💬 新会话                          [🔍 搜索] [⚙ 配置] │
└─────────────────────────────────────────────────────────┘
```
- 标题居中，使用 `font-weight: SEMIBOLD`
- 右侧操作按钮采用 ghost 样式，紧凑设计

### 2. 配置栏 (Config Bar)
```
┌─────────────────────────────────────────────────────────┐
│ [gpt-4o ▾] │ 🧠 Medium ▏ [My Project ▾]                │
└─────────────────────────────────────────────────────────┘
```
- 使用 pill 标签设计，背景 `gpui::rgba(0xFFFFFF08)`
- 分隔符使用 `▏` 字符，颜色 `gpui::rgba(0x555555FF)`

### 3. 消息气泡设计

#### 用户消息
```
┌─────────────────────────────────────┐
│ 你好，请帮我分析一下这个代码...     │  ← 右侧对齐
└─────────────────────────────────────┘
                                  14:32
```
- 背景: `gpui::rgba(0x3B82F620)` (蓝色半透明)
- 边框: `gpui::rgba(0x3B82F640)`
- 圆角: `rounded-lg`，左下角 `rounded-bl-md`

#### AI 消息
```
┌─────────────────────────────────────┐
│ 好的，我来帮你分析...               │  ← 左侧对齐
│                                     │
│ ```rust                            │
│ fn main() { ... }                   │
│ ```                                 │
└─────────────────────────────────────┘
                                  14:33
```
- 背景: `gpui::rgba(0xFFFFFF08)`
- 边框: `gpui::rgba(0xFFFFFF10)`
- 圆角: `rounded-lg`，右下角 `rounded-br-md`

### 4. 输入区域设计
```
┌─────────────────────────────────────────────────────────┐
│ 输入你的消息...                                       [发送]│
└─────────────────────────────────────────────────────────┘
```
- 输入区域占满剩余空间，最小高度 36px
- 发送按钮位于右侧，使用 primary 样式

### 5. 底部栏设计
```
┌─────────────────────────────────────────────────────────┐
│ [+ 新会话] [📜 历史] [👤 运行中(2)] [⚙ 设置]    15 条消息│
└─────────────────────────────────────────────────────────┘
```
- 按钮采用 ghost 样式，紧凑设计
- 代理状态徽章动态显示运行中的代理数量

### 6. 代理区块设计
```
┌─────────────────────────────────────────────────────────┐
│ 🔧 claude                  [✓ completed]        [折叠 ▼]│
├─────────────────────────────────────────────────────────┤
│ [渲染的 Markdown 内容...]                               │
└─────────────────────────────────────────────────────────┘
```
- 头部使用 `gpui::rgba(0xFFFFFF08)` 背景
- 运行状态使用脉冲动画效果
- 展开/折叠使用平滑过渡

## 动画与过渡
- 下拉菜单展开/收起：0.2s ease-out
- 代理区块展开/折叠：0.3s ease-in-out
- 消息出现：淡入效果 (opacity 0 → 1)

## GPUI 组件映射
- 消息气泡: `div().rounded_lg().bg(...).p(px(10.))`
- Pill 标签: `txt(...).bg(gpui::rgba(0xFFFFFF08)).rounded_full().px(px(8.)).py(px(3.))`
- 输入框: `Input::new(entity)`
- 按钮: `Button::new(...).ghost().compact()` / `.primary()`
- 滚动区域: `ScrollableElement`
