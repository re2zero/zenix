# PRD: zenixAI 会话界面完整重构

## 背景与问题
当前 zenixAI 的会话界面存在严重问题：
1. **不符合 AI Agent 风格**：界面设计普通，没有体现 AI Agent 的智能感和专业性
2. **对话流程不完整**：缺乏正常的 AI 对话体验，用户输入和 AI 回复的交互不流畅
3. **功能不完善**：缺少工具调用可视化、代理调度状态展示、思考过程展示等核心 AI Agent 功能

## 目标
完整重构 zenixAI 会话界面，打造符合现代 AI Agent 风格的对话界面，包括：
1. 现代化的 AI 聊天界面设计（参考 Cursor、Claude、Vercel AI 等）
2. 完整的对话流程：用户输入 → AI 思考 → 工具调用 → 代理调度 → 最终回复
3. 核心功能可视化：思考过程展示、工具调用状态、代理执行状态

## 设计风格
采用 **"Modern AI Agent Minimalist"** 设计风格：
- 深色主题为主，支持主题切换
- 极简、专业的视觉设计
- 清晰的思考过程展示（Thinking/Tool Calling/Agent Dispatch）
- 流畅的动画和过渡效果

## 核心功能模块

### 1. 对话消息区域
- **用户消息**：右侧对齐，主题色背景，圆角设计
- **AI 消息**：左侧对齐，深色背景，支持 Markdown 渲染
- **思考过程展示**：AI 思考过程中的中间状态展示（折叠面板）
- **工具调用展示**：显示 LLM 调用的工具和结果

### 2. 代理调度展示
- **代理区块**：显示当前正在执行的代理任务
- **状态指示**：运行中、已完成、失败等状态
- **实时输出**：代理执行过程中的实时输出预览

### 3. 输入区域
- **多行输入**：支持 Enter 发送，Shift+Enter 换行
- **发送/停止按钮**：根据 AI 是否流式回复动态切换
- **配置栏**：模型选择、思考级别、工作空间选择

### 4. 顶部 Header
- 会话标题显示
- 搜索、配置、新建会话、历史等操作按钮

## 技术实现要点
- 使用 GPUI 组件库的现代化样式
- 优化 Markdown 渲染组件
- 添加工具调用和代理状态的可视化组件
- 保持与现有主题系统的兼容性

## 验收标准
- [ ] 界面符合现代 AI Agent 风格
- [ ] 完整的对话流程：用户输入 → AI 回复
- [ ] 思考过程可视化展示
- [ ] 工具调用状态展示
- [ ] 代理调度状态展示
- [ ] 输入区域支持多行输入和快捷键
- [ ] 发送/停止按钮动态切换
