# PRD: 修复透明度滑块交互和回滚输入框编辑问题

## 问题 1: 透明度滑块
- **当前状态**: 滑块不可拖动，数值和进度条不同步，最低限制 50%（应为 30%），透明度未真实生效
- **需求**:
  1. 实现可拖动的滑块交互（鼠标拖拽 thumb 更新值）
  2. 进度条填充与数值实时同步
  3. 最低值改为 30%
  4. 透明度值需要应用到终端渲染（检查 config 保存和终端渲染器是否读取）

## 问题 2: 回滚行数输入框
- **当前状态**: 中间显示数值但点击不可编辑，"+" 按钮后的"行"文字多余
- **需求**:
  1. 输入框应可点击编辑（检查 Input 是否正确渲染）
  2. 删除"+"按钮后的"行"文字标签

## 接受标准
1. ✅ 透明度范围改为 30%-100%
2. ✅ 透明度值应用到终端背景
3. ✅ 回滚行数输入框可编辑（使用 default_value）
4. ✅ "+"按钮后无"行"文字
5. ❌ 滑块拖动交互（需要添加鼠标事件处理）

## 修改文件
- `src/ui/settings/tabs.rs` — 修改滑块范围，删除"行"文字
- `src/terminal/element.rs` — 添加 opacity 参数并应用到背景
- `src/app.rs` — 传递 opacity 到 TerminalElement，使用 default_value
